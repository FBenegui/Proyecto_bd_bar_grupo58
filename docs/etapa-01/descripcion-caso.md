1. Descripción del caso

El proyecto consiste en el desarrollo de un Sistema de Gestión de Ventas para un Bar, destinado a administrar las principales operaciones relacionadas con la venta de bebidas y productos ofrecidos por el establecimiento.
El sistema permitirá gestionar clientes, productos, categorías, ventas, métodos de pago, usuarios y stock. Además, permitirá registrar las recetas asociadas a determinados productos y los ingredientes necesarios para su elaboración.
El objetivo es centralizar la información del negocio y facilitar el registro de las operaciones, reduciendo errores y permitiendo mantener actualizados los datos relacionados con las ventas, los productos y el stock disponible.
