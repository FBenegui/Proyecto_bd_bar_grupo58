2. Alcance del sistema

El sistema abarcará las principales operaciones internas relacionadas con la gestión de un bar.
Dentro del alcance

El sistema permitirá:
    • Registrar, modificar y consultar clientes. 
    • Registrar, modificar y consultar productos. 
    • Asociar productos a categorías. 
    • Gestionar el stock de productos e ingredientes. 
    • Registrar ventas. 
    • Asociar cada venta a un cliente. 
    • Asociar cada venta al usuario responsable de realizarla. 
    • Registrar el método de pago utilizado. 
    • Registrar los productos incluidos en cada venta. 
    • Conservar el precio unitario utilizado al momento de realizar una venta. 
    • Consultar el historial de ventas. 
    • Consultar precios registrados en operaciones anteriores. 
    • Gestionar usuarios y roles. 
    • Registrar y consultar recetas. 
    • Registrar los ingredientes utilizados en las recetas. 
    • Generar reportes básicos. 

    Fuera del alcance

Para mantener el proyecto acotado a los objetivos de la materia, no se contemplan:
    
    • Facturación electrónica. 
    • Gestión de sueldos. 
    • Contabilidad completa del negocio. 
    • Delivery. 
    • Integración con plataformas externas de pedidos. 
    • Gestión avanzada de promociones.
